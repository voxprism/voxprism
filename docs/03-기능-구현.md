## 3. 모듈별 구현

### 3.1 작업 접수 — `web/main.py`, `store.py`, `worker.py`

- **업로드** `create_job`: 확장자 검사 → `.upload-<id>/input<ext>`에 1MB씩 쓰며 누적 크기 검사(413) → `store.create_job`(options + status queued) → 작업 폴더로 이동. 어느 단계든 실패하면 폴더를 지움. (FR-JOB-01~02)
- **옵션 정리**: 제목은 줄바꿈·탭 제거 후 80자, 출연자 수는 0~12로 자르고 0이면 `None`(자동), 엔진은 허용값 외 `auto`.
- **대기열** `store.next_queued`: 작업 폴더를 이름순으로 훑어 첫 `queued`. 워커는 대기 작업이 없으면 렌더 요청(`render.request`)을 보고, 둘 다 없으면 1초 쉼. (FR-JOB-03)
- **복구** `store.recover_interrupted`: 워커 시작 시 `running`이면 `retries`<1 → 재대기, 아니면 error. (FR-JOB-07)
- **삭제**: `running`이면 409, 아니면 폴더 통째로 삭제. (FR-JOB-06)

### 3.2 처리 흐름 — `pipeline/run.py`

- `process(job_id)`가 6단계를 순서대로 부르고, 단계마다 `Progress`로 `status.json`을 갱신합니다(단계별 진행률 구간은 `STAGE_RANGE`).
- 예외 처리: `UserError`(오디오 없음·20분 초과·인식된 말 없음)는 문구 그대로 보여 주고, 그 밖의 예외는 "처리 중 오류가 발생했습니다." + `detail`(유형과 앞 500자). (FR-JOB-05)
- `build_speakers`: 화자별 말한 시간(turns 합) 내림차순으로 `S1…` 부여, 팔레트 색, 대표 대사(긴 문장 2개). (FR-CAP-06)
- `_thumbnails`: 겹치지 않는 긴 구간 우선, 서로 5초 넘게 떨어진 가운데 시점 최대 3장. (FR-CAP-06)
- `render`: `render.json`을 running으로 → 자막 재생성 → `media.burn_in` → done/error, 끝나면 `render.request` 삭제. (FR-VIEW-07)

### 3.3 음성 인식 — `pipeline/asr*.py`

- `resolve_engine`: `whisper`/`clova` 지정 시 그대로, `auto`면 CLOVA 키가 있을 때 clova.
- `asr_clova.recognize`: `{invoke}/recognizer/upload`에 multipart(`media` + `params` JSON), 헤더 `X-CLOVASPEECH-API-KEY`. params: `language=ko-KR`, `completion=sync`, `wordAlignment`, 필요 시 `diarization`·`sed`.
- `asr_clova.to_words`: 세그먼트의 `words`([시작ms, 끝ms, 글자])를 초 단위 단어로 바꾸고 세그먼트 화자를 `src_spk`로 붙임. `to_sound_events`: 이벤트 라벨을 한국어(`SED_LABELS_KO`)로.
- `asr.recognize`: 이벤트 탐지 auto — "event" 오류면 끄고 재요청, 워커 프로세스 동안 기억(`_sed_supported`). CLOVA가 어떤 이유로든 실패하면 Whisper로 대체하고 경고. (FR-CAP-01, 07)
- `asr.recognize_batch`: 겹친 말 재인식용(화자 인식·이벤트 탐지 없음). 실패 시 Whisper(VAD 끔).

### 3.4 화자 분리 — `pipeline/diarize.py`, `assign.py`

- `get_pipeline`: community-1을 먼저, 실패하면 3.1(`Pipeline.from_pretrained(name, token=HF_TOKEN)`), 스레드는 `WHOSAID_THREADS`.
- `diarize`: pyannote 4의 `DiarizeOutput`에서 `speaker_diarization`(turns)과 `exclusive_speaker_diarization`(exclusive)을 꺼냄. 진행률 훅 `_Hook`.
- `overlap_regions`: 시작·끝 이벤트를 쓸어 2명 이상 동시 구간 → 0.25초 미만 버림, 0.2초 이내 병합. `exclusive_from_turns`: CLOVA 화자 정보만 있을 때 배타 구간을 만듦.
- `speaker_centroids`: 겹침 ±0.1초를 뺀 혼자 말한 구간에서 1초 이상 조각을 길이순 최대 8개, 가운데 최대 6초를 임베딩해 평균. 없으면 0.6초 이상 아무 구간. (FR-OVL-02)
- `assign.assign_words`: 이분 탐색으로 단어 중앙을 덮는 구간 찾기 → 규칙 3단계. (FR-CAP-04)

### 3.5 겹친 말 복원 — `pipeline/overlap.py`, `separate.py`

- `plan_regions` → `Plan`(구간, 창, 두 화자, 유사도, 확신도, 에너지, 분리음). 대표 벡터가 2개 미만이면 아무것도 하지 않음.
- `separate.separate`: SepFormer `separate_batch`, 출력 (2, T). `normalize`, `rms_db`로 에너지 비교.
- `build_batch` / `map_back`: 조각 오프셋 색인 `(plan, source, offset, length)`로 재인식 단어를 되돌림.
- `resolve`: 상세설계 8절 의사코드 그대로. 반환 `(recovered, reassign, details)`; `run.process`가 재배정을 단어에 반영하고 `reassigned=True` 표시. (FR-OVL-04~06)

### 3.6 자막 — `pipeline/captions.py`, `subtitles.py`

- `build_events` → `_polish_timing` → `mark_overlaps` (상세설계 9절 표의 규칙).
- `resolve_speakers`: `speakers.json` 편집을 합쳐 `{원래 id: {id, name, color}}`, `_sfx`(소리, #DDDDDD)와 `UNK`('?')를 항상 포함.
- `to_srt` / `to_vtt` / `to_ass`; `subtitles.write_all`이 세 파일을 `subs/whosaid.*`로 씀(SRT만 UTF-8 BOM).
- 자막 입힌 MP4: `assign_lanes`(줄 배정) → `to_ass_burn`(말풍선·표시줄·꼬리·선을 ASS 그리기 명령으로) → `subtitles.write_burn`이 `subs/burn.ass`로 씀 → `run.render`가 이 파일로 굽기. 글자 폭은 `_Measure`(Pillow + Noto Sans CJK KR Bold, 없으면 어림값).

### 3.7 웹 화면 — `web/static/`

| 화면 | 파일 | 하는 일 |
| --- | --- | --- |
| 로그인 | `login.html` | 비밀번호, 실패 문구(`?error=1`), `next` 유지 |
| 홈 | `index.html`, `index.js` | 끌어 놓기·키보드로 파일 선택, 옵션, XHR 업로드 진행률, 최근 작업(새로고침) |
| 작업 | `job.html`, `job.js` | 단계 진행 표시, 플레이어 + `requestAnimationFrame` 자막 오버레이(고정 줄 말풍선 `assignLanes`, 화자 표시줄 `renderStage`, 꼬리·선 `layoutLinks`, 작은 화면 `fitStage`), 보기 설정, 화자 카드(이름·합치기·장면 클릭 이동), 대본(따라가기·클릭 이동·동시/복원 표시), 다운로드, MP4 만들기, 삭제 |
| 공통 | `common.js`, `app.css` | `$`, 이스케이프, 시간 형식, 색 변수, `[hidden]` 강제 |

빌드 도구 없이 바로 쓰는 HTML/CSS/JS입니다. 서버는 정적 파일에 `Cache-Control: no-cache`를 붙여 배포 직후 새 화면이 보이게 합니다.

## 5. 로컬에서 돌리기

```bash
# 가벼운 개발 (웹 + 테스트, 모델 없음)
python3 -m venv .venv && . .venv/bin/activate
pip install "fastapi>=0.115" "uvicorn[standard]" python-multipart requests "numpy>=2.0" soundfile pytest httpx
cd app && python -m pytest -q tests                      # 12 passed
WHOSAID_DATA_DIR=/tmp/voxprism python -m uvicorn whosaid.web.main:app --reload   # 비밀번호 없으면 로그인 생략

# 전체 (워커까지): 서버와 같은 의존성 설치 후
pip install -r app/requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
HF_TOKEN=... CLOVA_SPEECH_INVOKE_URL=... CLOVA_SPEECH_SECRET=... python -m whosaid.worker
```

키는 셸에 직접 쓰지 말고 `set -a; . ../secrets/keys.env; set +a`로 읽어 들입니다(값이 기록에 남지 않게).

## 6. 기술 부채

| 항목 | 영향 | 다음에 할 일 |
| --- | --- | --- |
| HTTPS 없음 | 비밀번호가 평문 전송 | 도메인 + Let's Encrypt |
| 단일 워커 | 동시에 여러 작업이면 대기 | 필요할 때 워커 수·큐 도입(스펙 먼저) |
| CLOVA·pyannote 경로 자동 테스트 없음 | 외부 API·모델 회귀를 CI가 못 잡음 | 녹화 응답(fixture)으로 변환 함수 테스트 |
| UI 자동 테스트 없음 | 화면 회귀는 수동 확인 | 핵심 흐름 Playwright 스모크 테스트 |
| `infra/` 테스트 없음 | 스크립트 회귀 | shellcheck CI 추가 |
