# SPEC-004 자막 보기·화자 편집·내보내기

## 1. 배경과 문제

자막 파일만 주면 대부분의 플레이어는 화자 색을 보여 주지 못하고, 동시에 뜬 두 자막을 겹쳐 그립니다. 사용자는 처리 결과를 바로 보면서 화자 이름을 고치고, 원하는 형식으로 가져갈 수 있어야 합니다. 휴대폰처럼 자막 파일을 못 쓰는 곳을 위해 자막을 입힌 영상도 필요합니다.

## 2. 목표 / 하지 않는 것

- 목표: 브라우저 플레이어 위 화자 색·이름표 자막, 보기 설정, 대본 이동, 이름 붙이기·합치기, SRT·VTT·ASS·JSON·MP4 내보내기.
- 하지 않는 것: 자막 문장 직접 편집, 화자 나누기, 유튜브 위 표시(브라우저 확장).

## 3. 사용자 시나리오

1. 화자 카드의 장면 썸네일을 눌러 그 장면을 보고, '화자 1'을 '유재석'으로 바꾼 뒤 '이름 저장'.
2. 같은 사람이 S2·S4로 나뉘었으면 S4의 '합치기'에서 S2를 고른다. 자막과 내려받을 파일이 바로 바뀐다.
3. 글자를 '아주 크게', 위치를 '위'로 바꿔 전체 화면으로 본다.
4. 대본에서 '복원' 표시가 붙은 줄을 눌러 그 장면으로 간다.
5. '자막 입힌 영상(MP4) 만들기' → 완료되면 내려받아 휴대폰으로 본다.

## 5. 수용 시나리오

```gherkin
시나리오: 화자 합치기
  조건 처리가 끝난 작업에 S1, S2, S3가 있다
  만일 S3를 S1로 합치고 저장하면
  그러면 SRT의 S3 줄은 S1의 이름으로 바뀌고 VTT 색도 S1 색이 된다
  그리고 이전에 만든 burned.mp4는 지워진다

시나리오: 자기 자신으로 합치기
  만일 S1을 S1로 합치려 하면
  그러면 합치기는 무시되고 이름만 저장된다
```

## 6. 영향과 위험

- 이름은 사용자가 입력하므로 자막·파일에 그대로 들어감 → 30자 제한, HTML·VTT·ASS 이스케이프.
