# SPEC-007 품질 평가 체계

## 1. 배경과 문제

"겹친 말이 잘 나온다"를 눈으로만 판단하면 개선인지 퇴보인지 알 수 없습니다. 실제로 첫 복원 버전은 겹친 말을 더 찾았지만 엉뚱한 화자에게 붙여 전체 품질을 떨어뜨렸습니다. 한국어 다화자 겹침 대화에 정답이 있는 공개 데이터는 찾기 어렵습니다.

## 2. 목표 / 하지 않는 것

- 목표: 정답이 있는 겹침 대화를 만들고, 화자까지 맞았는지 재는 지표로 '일반 자막 → 화자 구분 → 복원'을 같은 잣대로 비교.
- 하지 않는 것: 실제 예능에 정답 달기(사람 손이 많이 듦, 저작권), 대규모 벤치마크.

## 3. 사용자 시나리오

1. 운영자가 `make_test_set.py --speakers 3 --seed 7`로 3인 대화 영상과 정답을 만든다.
2. 영상을 업로드해 처리한다(복원 켬/끔, 출연자 수 입력/자동).
3. `evaluate.py --truth … --result … --baseline-asr …`로 지표 표를 얻는다.
4. 파이프라인을 바꾼 PR에 전후 표를 붙인다.

## 4. 요구사항

| ID | 요구사항 |
| --- | --- |
| FR-EVAL-01 | Zeroth-Korean test로 정답 있는 겹침 대화 생성 |
| FR-EVAL-02 | CER·cpCER·발화 재현율·겹친 발화 재현율·누락 수 |
| FR-EVAL-03 | 실행 묶음 조건별 평균 |
| FR-EVAL-04 | 정답·결과 시간축 비교 |
| NFR-QUAL-01 | 품질 기준선 (cpCER ≤ 0.40, 겹친 발화 재현율 ≥ 0.70) |

## 5. 지표

| 지표 | 뜻 | 좋은 방향 |
| --- | --- | --- |
| CER | 화자를 무시한 글자 오류율 | 낮을수록 |
| cpCER | 화자별로 이어 붙인 글자 오류율, 화자 짝은 최소 비용 순열(CHiME cpWER의 글자판) | 낮을수록 |
| 발화 재현율 | 정답 발화가 올바른 화자의 자막에 담긴 비율(부분 문자열 편집 거리) | 높을수록 |
| 겹친 발화 재현율 | 위 지표를 다른 화자와 겹친 발화에서만 | 높을수록 |
| 겹친 발화 재현율(화자 무관) | 화자가 틀려도 글자가 어딘가에 있으면 인정 | 높을수록 |
| 사라진 겹친 발화 | 재현율 0.3 미만인 겹친 발화 수 | 적을수록 |

## 6. 현재 기준선 (평가셋 v2, 3개 영상, 겹친 발화 35개)

| 조건 | cpCER | 발화 재현율 | 겹친 발화 재현율 | 사라진 겹친 발화 |
| --- | --- | --- | --- | --- |
| 일반 자막 | 1.137 | 0.200 | 0.166 | 28 |
| 출연자 수 자동, 화자 구분만 | 0.559 | 0.525 | 0.456 | 13 |
| 출연자 수 자동, 복원 | 0.523 | 0.624 | 0.589 | 9 |
| 출연자 수 입력, 화자 구분만 | 0.450 | 0.605 | 0.535 | 10 |
| **출연자 수 입력, 복원** | **0.344** | **0.768** | **0.752** | **3** |

원자료: `docs/eval_v2.json`, `docs/runs_v2.json`.
