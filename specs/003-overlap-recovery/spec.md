# SPEC-003 겹친 말 복원

## 1. 배경과 문제

두 사람이 동시에 말하면 음성 인식은 큰 목소리 한쪽만 받아 적거나 두 문장을 섞습니다. 맞장구·끼어들기·리액션처럼 예능의 재미를 만드는 말이 가장 먼저 사라집니다. 합성 평가셋에서 일반 자막은 겹친 발화 35개 중 28개를 사실상 놓쳤습니다.

## 2. 목표 / 하지 않는 것

- 목표: 겹친 구간에서 두 목소리를 나눠 다시 받아 적고, (a) 잘못 배정된 단어를 바로잡고 (b) 묻힌 사람의 말을 '복원' 자막으로 더한다. 확신이 낮으면 표시해서 사용자가 판단하게 한다.
- 하지 않는 것: 3명 이상 동시 발화 분리, 배경음악 제거, 실시간 처리.

## 3. 사용자 시나리오

1. B가 길게 말하는 동안 A가 "아 진짜?"라고 맞장구친다.
2. 일반 자막에는 B의 말만 있지만, VoxPrism에서는 A의 "아 진짜?"가 A 색으로 B 자막과 동시에 뜬다.
3. 대본에서 그 줄에는 '복원' 표시가 붙는다. 화자 확신이 낮으면 이름표에 '?'가 붙는다.
4. 사용자가 업로드 때 '겹친 말 복원'을 끄면 처리 시간이 약 절반이 되고 복원 줄은 생기지 않는다.

## 5. 수용 시나리오

```gherkin
시나리오: 묻힌 맞장구 복원
  조건 원래 자막에는 B의 단어만 있고, 분리음 A에서 "아 진짜"가 인식됐다
  그리고 "아 진짜"가 B의 원래 말과 비슷하지 않다
  그러면 "아 진짜"가 A의 recovered 단어로 추가된다

시나리오: 분리 실패로 새어 나온 말
  조건 분리음 A의 텍스트가 B의 원래 말과 유사도 0.6 이상이다
  그러면 아무것도 복원하지 않는다

시나리오: 화자 확신 낮음
  조건 1·2위 화자 조합 점수 차가 0.05 미만이다
  그러면 단어 재배정은 하지 않고, 복원 단어는 uncertain=true 이다
```
