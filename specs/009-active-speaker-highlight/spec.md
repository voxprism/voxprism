# SPEC-009 화면 속 말하는 사람 강조와 화면 밖 화자 표시

## 1. 배경과 문제

목표는 청각장애인이 예능을 볼 때 **누가 무슨 말을 하는지 자막으로 쉽게 아는 것**입니다. 이름표('화자 2')만으로는
화면 속 누구인지 다시 찾아야 하고, SPEC-008의 화자 표시줄(칩)도 화면 속 사람과 연결되지 않습니다.
사용자(프로젝트 주인) 요구(2026-11-19):

> 지금 말하고 있는 사람을 하이라이트 쳐 주고 겉 윤곽색으로 표시, 윤곽색과 같은 색의 자막 윤곽. 자막 위치는 항상
> 영상 위쪽 고정. YOLO 같은 걸로 말하는 사람을 인식하고, 그 사람의 목소리도 함께 기억(같은 사람이 화면 밖에서
> 말할 수도 있으므로). 화면에 아예 안 나오고 밖에서만 말하는 사람은 밖에서 다른 사람이 말하고 있다고 표시하고
> 자막은 계속. 잡음은 거르고, 동시에 말하는 것도 목소리별로 분리.

## 2. 목표 / 하지 않는 것

- 목표
  - 영상에서 얼굴과 사람 윤곽을 찾고, 장면이 바뀌어도 같은 사람의 얼굴을 묶는다.
  - 영상 한 편 안에서 **얼굴과 목소리(화자 분리 화자)를 연결**한다. 확신이 없으면 연결하지 않는다.
  - 연결된 사람이 화면에 있고 그 목소리가 나오면 **그 사람의 몸 윤곽을 화자 색으로 그리고 옅게 칠한다**.
  - 자막은 **영상 위쪽 고정 줄**에 띄우고, 말풍선 윤곽(테두리)을 같은 화자 색으로 한다.
  - 연결된 사람이 화면에 없을 때 말하거나, 어떤 얼굴과도 연결되지 않은 목소리는 자막에 **'화면 밖'**을 붙인다.
  - 잡음(신뢰도 낮은 짧은 인식, 지어낸 문장, 잠깐 잡힌 가짜 화자)을 거른다.
  - 동시 발화 분리(SPEC-003)는 그대로 쓰고, 분리된 말도 같은 규칙으로 강조·표시한다.
  - 자막 입힌 MP4도 같은 모양.
- 하지 않는 것
  - 영상 사이에 사람 기억(다음 영상에서 같은 이름) — 얼굴·목소리 데이터 보관 정책이 필요해 별도 스펙.
  - 얼굴로 실명 찾기(출연자 DB).
  - 학습이 필요한 시청각 화자 검출 모델(TalkNet 등) — CPU 서버 처리 시간, 한국어 예능 일반화 검증 후 검토.

## 3. 사용자 시나리오

1. 2인 인터뷰. 진행자가 말하면 진행자 몸에 파란 윤곽이 생기고, 위쪽 자막도 파란 테두리로 뜬다. 출연자가 대답하면
   윤곽이 출연자에게 노란색으로 옮겨 간다.
2. 둘이 함께 걷는 장면에서 한 명만 말한다 → 말하는 사람에게만 윤곽.
3. 풍경 장면에 진행자 내레이션 → 윤곽 없음, 자막에 '화면 밖'.
4. 끝까지 얼굴이 안 나오는 제작진 목소리 → 모든 자막에 '화면 밖'.
5. 박수 소리가 '짝'으로 인식됐거나, 0.5초짜리 가짜 화자가 생겼다 → 자막에 나오지 않는다.

## 4. 요구사항

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| FR-VIS-01 | 영상에서 얼굴(위치·특징점)과 사람 윤곽을 찾는다 | 얼굴 초당 10프레임, 윤곽은 강조할 프레임만 초당 5프레임 |
| FR-VIS-02 | 같은 사람의 얼굴을 영상 전체에서 묶는다 | 장면 전환에서 트랙을 끊고, 얼굴 특징 유사도로 사람 단위로 묶음 |
| FR-VIS-03 | 얼굴과 목소리를 연결한다 | 동시 출현 + 입 움직임 근거, 근거 1.5초 이상·점수 기준 통과 쌍만 1:1, 아니면 연결 안 함 |
| FR-VIS-04 | 말하는 사람을 영상 속에서 강조한다 | 화자 색 윤곽 + 옅은 채움, 연결된 사람이 보이고 그 목소리가 나올 때만 |
| FR-VIS-05 | 화면 밖 화자를 자막에 표시한다 | 연결 안 된 목소리, 또는 자막 시간의 30% 미만만 얼굴이 보임 → '화면 밖'. 얼굴이 하나도 없는 영상은 표시 안 함 |
| FR-VIS-06 | 화면 분석이 안 되면 자막만 낸다 | 모델 없음·실패 → 경고 남기고 계속, 결과에 윤곽·'화면 밖' 없음 |
| FR-CAP-08 | 잡음을 거른다 | 신뢰도 < 0.25 단어, 신뢰도 < 0.6인 0.5초 이하 외톨이 단어, Whisper 지어낸 문장, 합계 1초 미만·단어 2개 이하 화자 제거 |
| FR-VIEW-08 | (개정) 자막은 영상 **위쪽** 고정 줄 말풍선 | 첫 줄이 맨 위, 끝날 때까지 줄 유지 |
| FR-VIEW-09 | (개정) 말하는 사람 강조는 FR-VIS-04·05로 | SPEC-008 화자 표시줄은 없앰 |
| FR-VIEW-10 | (개정) MP4도 같은 모양 | 위쪽 줄 말풍선, 윤곽, '화면 밖' |
| NFR-PERF-03 | 화면 분석 시간 | 영상 길이의 0.5배 이하(c8-g3) |
| NFR-PRIV-02 | 얼굴 정보 보관 | 얼굴 특징값은 파일로 남기지 않음. 얼굴 사진·윤곽은 작업 폴더에만, 작업 삭제 시 함께 삭제 |

## 5. 수용 시나리오

```gherkin
시나리오: 동시 출현과 입 움직임으로 얼굴과 목소리를 잇는다
  조건 A가 0~10초, B가 10~20초 말하고, P1은 0~12초, P2는 8~20초 보인다
  그리고 8~10초에는 둘 다 보이는데 P1만 입을 움직인다
  만일 연결하면
  그러면 A=P1, B=P2

시나리오: 근거가 없으면 잇지 않는다
  조건 P1이 보일 때 B가 1초만 말했다
  그러면 B는 어떤 얼굴과도 연결되지 않고 B의 자막에는 '화면 밖'이 붙는다

시나리오: 얼굴이 없는 영상
  조건 음성 파일이거나 사람이 안 나오는 영상
  그러면 '화면 밖' 표시와 윤곽 없이 자막만 나온다

시나리오: 잡음
  조건 신뢰도 0.2인 '맞아요', 앞뒤 1.5초 안에 말이 없는 신뢰도 0.4 '쿵'
  그러면 둘 다 자막에 없다
```

## 6. 영향과 위험

- 영향: SPEC-008(화자 표시줄·아래 자막 → 없앰/위쪽), SPEC-004(보기 설정에서 '위치' 없앰), SPEC-002(잡음 거르기).
- 위험
  - 잘못 연결하면 엉뚱한 사람이 강조됨 → 기준을 보수적으로, 점수표를 visual.json에 남겨 확인 가능하게.
  - 뒷모습·옆모습·작은 얼굴은 못 찾아 강조 누락, 자막에는 '화면 밖'이 붙을 수 있음(얼굴 기준 판정).
  - 편집된 영상의 "말하는 사람을 비춘다" 가정에 기대는 부분이 있음 → 말 없는 사람 위 내레이션(B-roll)은 입 움직임 대비로 막지만 완전하지 않음.
  - YOLO11 가중치는 AGPL-3.0 → 저장소 공개 운영 중이라 소스 공개 의무와 충돌은 없음. 라이선스 정책은 열린 질문.
