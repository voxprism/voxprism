# /sdd-handoff — 인수인계 갱신

1. `docs/06-인수인계.md`의 **지금 상태** 표를 사실대로 고친다: 브랜치, 진행 중 스펙과 남은 작업, 서버 상태(사용자가 확인해 준 경우만), 알려진 문제.
2. **다음 할 일**을 우선순위 순서로 정리한다(스펙 ID 포함).
3. **세션 기록** 표 맨 위에 한 줄: 날짜 · 한 일 · 남긴 것.
4. 확인한 사실과 추측을 구분한다. 측정하지 않은 수치는 쓰지 않는다.
5. 커밋 `docs(handoff): 인수인계 갱신`.
